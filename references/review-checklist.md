# 论文审查清单

## 0. 先确认

- [ ] 本次是只读检查，还是检查并修改？
- [ ] 目标页数是多少？当前页数是多少？是否允许加页？
- [ ] 学校范本和格式要求是否为最新版？
- [ ] Word 是否占用论文文件（`~$` 锁文件）？
- [ ] 是否有交接说明、项目源码或旧版 PDF 可供对照？
- [ ] 如果包含结构审查：是否已读取 `thesis-structure-profile.md`，并找到总体功能模块图？
- [ ] 是否已从总体功能模块图读取角色名称、数量、左右顺序，并另行确认章节标题中的角色名？标题写法默认与图中角色名称相同，简称或其他改名需记录映射。
- [ ] 第4章采用角色型还是功能型？未明确时是否已确认默认角色型？
- [ ] 是否确认了唯一准稿路径，未混用同一论文的旧版截图、旧版 PDF 或备份？
- [ ] 是否记录了用户明确接受的当前论文例外，并确认这些例外不会被推广到其他论文？


## 0.1 结构规范（按总体功能模块图）

- [ ] 总体功能模块图存在；不按“图3.1”或其他固定图号猜测。
- [ ] 角色顺序来自总体功能模块图从左到右的排列；图中不清晰或冲突时已询问用户。
- [ ] 2.1下三级标题数量、顺序与总体功能模块图角色一致。
- [ ] 角色型标题、图题、表题和简易图中的角色名称是否统一；正文简称是否已经用户允许。
- [ ] 3.2下三级标题数量、顺序与角色一致，每个角色包含功能说明和流程图。
- [ ] 角色型第4章的三级标题是否对应项目实际角色功能；不要求与总体功能模块图第三层及以下节点逐项一致，不同角色下可出现同名功能。
- [ ] 功能型第4章的具体功能名来自第二层角色分支下的全部功能节点，包括第三层及更深层；按连线归属判断，不按纵向层数漏掉功能；无法确认时已询问用户。
- [ ] 第4章标题的“功能/功能实现”后缀符合选定写法，且没有重复叠加。
- [ ] 第4章采用已确认的角色型或功能型结构；每个功能包含说明、功能图和核心代码。
- [ ] 5.2下三级标题数量、顺序与角色一致，每个角色包含说明和测试表。
- [ ] 2.2.2及之后可选小节若存在则保留；标题不机械套用当前论文。
- [ ] 4.1等一般界面流程句不因角色目录顺序被机械改写。

## 1. 文档结构

- [ ] 封面、诚信声明、目录、中文摘要、英文摘要齐全。
- [ ] 章节编号连续，目录条目与正文标题一致。
- [ ] 目录是 Word 域，缓存页码与当前分页一致。
- [ ] 结论、参考文献、致谢均有独立标题。
- [ ] 页码体系正确：目录 i/ii/iii，摘要 I/II，正文 1…。
- [ ] 页眉从目录页开始，页脚页码居中。

## 2. 格式

- [ ] 一级、二级、三级标题的字体、字号、行距、段前段后、对齐正确。
- [ ] 标题中的数字和字母为 Times New Roman。
- [ ] 目录中的章节号、页码等数字和英文为 Times New Roman。
- [ ] 中文摘要“关键词：”顶头；英文摘要 `Keywords:` 顶头。
- [ ] 英文题目可写两行，使用软回车（Shift+Enter）换行。
- [ ] 结论、参考文献、致谢标题段前 1 行、段后 1 行。
- [ ] 正文中文宋体小四，英文数字 Times New Roman 小四，固定 22 磅，首行缩进 2 字符。
- [ ] 图题 5 号黑体居中固定 20 磅，位于图下方。
- [ ] 表题 5 号黑体居中固定 20 磅，位于表上方。
- [ ] 表格为三线表，宽约 16cm，上下 1.5 磅、中间 0.5 磅、无左右边线。
- [ ] 表内文字五号，1.5 倍行距，标题行在跨页时重复。
- [ ] 代码块中文宋体五号，其余 Times New Roman 五号，代码框不跨页。
- [ ] 参考文献五号、单倍行距、段前 0.5 行、悬挂缩进 0.6cm。
- [ ] 致谢正文宋体小四，英文数字 Times New Roman 小四，22 磅行距。

## 3. 图表

- [ ] 图号、表号连续，没有跳号或重号。
- [ ] 正文“如图/表 X.X 所示”与题注一一对应，引用句没有被分页拆开。
- [ ] 同一图片是否被多个不同图题复用。
- [ ] 图题描述与截图内容是否一致（例如“语义重排”图里是否真的选了“混合+重排”）。
- [ ] 截图是否被拉伸、压扁、裁切或跨页；用户允许轻微缩放时，图中关键文字和操作是否仍可辨认。
- [ ] 表格每一行是否为独立 `w:tr`；有没有把两个逻辑行塞进同一行的不同段落。
- [ ] 表格是否断页，断页后第二页顶部是否有续表题，标题行是否重复。

## 4. 内容一致性

- [ ] 摘要、第 5 章、结论中的用例数、指标、策略名和结论一致。
- [ ] 第 2/3 章提出的功能，第 4 章有对应实现，第 5 章有对应测试。
- [ ] 模块数量、角色名称、权限归属前后一致。
- [ ] 代码块与正文描述的接口、变量、数据流和返回字段对应。
- [ ] 代码块是精简摘录时，是否用简短注释或正文说明了关键省略；是否与本节功能对应（不强制补全所有变量）。
- [ ] 图题、正文和代码是否描述同一个功能。
- [ ] 日期、姓名、学号、导师、企业导师等信息一致。
- [ ] 术语统一（例如 Vue3/Vue 3、BM25/bm25、知识专员/知识管理员）。
- [ ] 参考文献正文引用与文献表一一对应，编号连续。

## 5. 参考文献

- [ ] 中文条目五号宋体，英文条目五号 Times New Roman。
- [ ] `[J].`、`等.`、`:` 后有空格。
- [ ] 期刊有年、卷(期)、起止页。
- [ ] 会议有会议名称、地点、年份。
- [ ] 专著 `[M]` 有书名、版次（如有）、出版地、出版者、出版年。
- [ ] 学位论文有学校及学位级别、年份。
- [ ] EB/OL 有 URL 或 DOI，以及引用日期。
- [ ] 作者超过三位时用“等”或“et al”，姓名顺序为姓在前、名在后。

## 6. 交付前最后检查

- [ ] 在 Word 中更新整个目录域并保存。
- [ ] 导出 PDF，逐页检查分页、图表、代码框和页眉页脚。
- [ ] 检查 PDF 页码与目录页码一致。
- [ ] 检查文件能否正常打开，没有损坏提示。
- [ ] 确认修改范围没有超出用户授权。
- [ ] 将用户明确接受的例外记录为“已确认例外”，不重复当作未解决问题。
